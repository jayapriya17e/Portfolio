Online Exam Platform

Objective

The objective is to develop a secure system for conducting online multiple-choice exams with automatic evaluation and result generation.

Working

The Online Exam Platform is developed to conduct multiple-choice examinations in a secure and automated manner. The system is built using Java for the frontend interface and MySQL for database management. When a user logs in, the system verifies credentials from the database. After authentication, the student can start the exam. The platform dynamically loads questions from the database and displays them one by one. A timer is initiated when the exam begins, and the countdown is shown on the screen. Students select answers, which are temporarily stored during the exam. If the time expires or the student clicks submit, the system automatically submits responses. The answers are then evaluated by comparing them with correct answers stored in the database. The system calculates the score and displays the result immediately. An admin panel is also provided to add, modify, and delete questions. This ensures flexible management of exam content.
