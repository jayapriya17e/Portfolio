Audio Recording and Playback System

Objectives

The objective of this project is to design an embedded system capable of recording and playing back audio signals. The system captures voice input, stores it in memory, and reproduces the recorded audio when required.

Working

The system uses a microphone to capture audio signals, which are then converted into electrical signals. These analog signals are fed into the microcontroller through an ADC. The digitized audio data is stored in memory. When playback is requested, the stored digital data is retrieved and converted back into analog signals using a DAC. The analog output is amplified and sent to a speaker. The system allows users to record and play audio using control buttons.

Software Used

  • Embedded C
  • STM32CubeIDE
  • Proteus

Components Used

  • STM32F103RB
  • Microphone
  • Speaker
  • LM386 Amplifier
  • Push Buttons

Applications

  • Voice recording devices
  • Digital voice assistants
  • Security voice logging systems
  • Lecture recording systems
  • Smart home voice control
  • Portable audio recorders
